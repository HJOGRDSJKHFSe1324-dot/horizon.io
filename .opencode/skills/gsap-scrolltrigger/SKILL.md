# GSAP ScrollTrigger

See the installed gsap skill for full animation guidance.
Core patterns:
- Register plugin: gsap.registerPlugin(ScrollTrigger)
- Create pinned scrubbed sections with timeline + scrub/anticipatePin.
- Use matchMedia for responsive.
- Respect prefers-reduced-motion.
- Clean up with ScrollTrigger.getById().kill() and revert.
